# **App Name**: JobTrackr

## Core Features:

- Add Application: Add new job applications with details like company name, position, source (LinkedIn, Naukri, company website, others), application date, and job description (JD).
- Status Tracking: Track the status of each application (e.g., Applied, Phone Screen, Interview, Offer, Rejected).
- Notes and Action Items: Add notes for each application, including rounds completed, actionable items, and HR contact information.
- Application List: Display all job applications in a sortable and filterable table or list.
- JD Summarizer: AI-powered tool to summarize job descriptions and extract key skills and requirements. Use this information to automatically categorize the job for easier filtering and follow-up.

## Style Guidelines:

- Primary color: Neutral white or light grey for a clean and professional look.
- Secondary color: A calming blue (#3498db) for accents and interactive elements.
- Accent: Green (#2ecc71) to indicate positive statuses like 'Interviewing' or 'Offer'.
- Use a clean, card-based layout for displaying job applications.
- Use clear and consistent icons to represent application sources and status.
- Subtle transitions and animations for a smooth user experience when updating application status or adding notes.

## Original User Request:
An app that helps me track all my job applications, their status, notes, source(Linkedin/Naukri,Company website,Others) JD, company name, position, rounds completed, application date, my actionable(s), HR contact etc in one place.
